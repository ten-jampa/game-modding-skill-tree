# Later-Stage Tool — universal-modder

[`rehan-remade/universal-modder`](https://github.com/rehan-remade/universal-modder) is an AI-agent game modding workbench: engine scanning, route selection, asset generation, Windows game automation, publishing checks, and skills/playbooks for many engines.

It is cool as hell. It is also not step one.

## Use it as

- A workflow reference.
- A map of engines and modding routes.
- Inspiration for later automation.
- A source of safety practices.

## Do not use it as

- A beginner magic button.
- A substitute for understanding the game/loader.
- An excuse to skip backups.
- A way to touch online anti-cheat games.

## When to study it

After you can manually complete:

- one item
- one projectile
- one saved player stat
- one enemy
- one UI/progression slice
- one packaged mini release

Then read its `mod-any-game` and `game-recon` skills as an advanced operating loop.
