# Setup Checklist

- [ ] Pick one primary game.
- [ ] Confirm the modding route is allowed and community-supported.
- [ ] Install the game legally.
- [ ] Install the mod loader.
- [ ] Launch once before editing anything.
- [ ] Locate install folder.
- [ ] Locate save/mod data folder.
- [ ] Locate logs.
- [ ] Create a test character/world/profile.
- [ ] Create a mod journal.
- [ ] Initialize git before experiments.
