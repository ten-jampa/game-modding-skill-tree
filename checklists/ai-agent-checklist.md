# AI Agent Checklist

- [ ] Provide game, loader, version, OS, and goal.
- [ ] Ask for a plan before edits.
- [ ] Keep the requested change tiny.
- [ ] Review changed files.
- [ ] Run build/reload.
- [ ] Check logs.
- [ ] Test in-game.
- [ ] Commit only working slices.
- [ ] Never paste secrets.
- [ ] Never run unknown binaries.
- [ ] Never touch anti-cheat/online clients.
