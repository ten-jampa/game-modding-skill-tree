# Contributing

Keep this repo practical.

Good contributions:

- Clearer Mac setup steps.
- Better tModLoader examples.
- Small project milestones.
- Debugging checklists.
- Corrections to outdated APIs.

Bad contributions:

- Piracy/DRM/anti-cheat bypass instructions.
- Giant unverified AI-generated tutorials.
- Windows-only assumptions without saying so.
- Engine-specific claims without sources or version notes.
