# Capstone — NoviceRealms

A compact Terraria mod that proves you can connect content into systems.

## Required features

- [ ] 5 weapons
- [ ] 2 accessories
- [ ] 1 material chain
- [ ] 4 enemies
- [ ] 1 debuff
- [ ] 1 mini skill tree
- [ ] 1 boss
- [ ] 1 boss summon item
- [ ] 1 post-boss reward
- [ ] saved player progression
- [ ] basic custom UI
- [ ] release checklist

## Constraint

Every feature must enter through a working vertical slice.

No giant rewrites. No mystery blobs from AI agents. No “trust me bro” code.
