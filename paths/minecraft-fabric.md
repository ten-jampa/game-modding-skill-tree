# Minecraft Fabric

Java/Kotlin, Fabric API, Mixins, registries, data packs/resource packs. Good second branch for broad creative systems.

## When to branch here

After completing at least:

- one item/content mod
- one behavior/combat change
- one saved progression slice
- one debugging session from logs

## First project

Make the smallest possible mod that changes one visible thing and can be reverted cleanly.
